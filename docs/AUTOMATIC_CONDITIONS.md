# 자연어 날짜·관심지역 자동입력

기준: 2026-10-29. 기존 `/request/interpret`에 `resolve_conditions=true`를 지정한 경우에만 `condition_proposals`를 추가한다. 목적 분류와 기존 후속 요청·검색·A2/A3/A4·관측 합성·선택형 ML 추정은 재사용한다. 자동입력은 영상 검색이나 픽셀 처리·유료 API를 실행하지 않는다.

## 화면 사용

`2026년 7월 충남의 집중호우 전후 침수범위를 분석하고 싶어.`를 분석 목적에 입력하면, 입력이 550 ms 멈추거나 blur될 때 2026-07-01~2026-07-31과 충청남도 포함 사각 영역을 제안·적용한다. 한글 조합 중에는 새 조건 해석·기존 문맥 해석·추천 요청을 시작하지 않는다. 해석이 끝나기 전에는 검색 버튼을 활성화하지 않는다. 사용자가 최종 조건을 확인한 뒤 검색을 누른다.

날짜는 달력의 날짜 문자열이며 UTC 시각 변환으로 만들지 않는다. 연도·월, 완전한 날짜, 완전하게 적은 시작일~종료일을 지원한다. 월말·윤년(1900/2000/2100 포함)을 계산한다. 연도 없는 월, 상대 날짜, 잘못된 날짜, 불완전하거나 모호한 복수 날짜는 확인 요청으로 남긴다. 미언급 필드는 유지한다. 검색 기간 최대 366일을 유지하며, 사건 기준일이나 전·후 기간을 임의 생성하지 않는다.

시작일·종료일·좌표 네 개에 기본값/자동 설정/직접 수정 출처를 표시한다. 날짜는 필드별로 보호한다. 좌표는 한 사각형을 이루므로 어느 좌표든 직접 수정했으면 자동 지역 제안으로 네 좌표를 부분 덮어쓰지 않는다. 충돌 시 현재 값을 유지하고 `문장에서 다시 적용`을 눌렀을 때만 제안값으로 갱신한다. 지도 선택도 직접 수정으로 취급한다. 잘못되거나 미완성인 좌표는 AOI로 확정하지 않으며 지도·검색에 서로 다른 사각형을 보내지 않는다.

`useConditionInput.ts`의 단일 폼 상태에서 좌표 초안과 출처를 보관하고 유효 bbox를 파생한다. 폼·지도·검색은 이 값을 공유한다. 입력 이벤트에서 문장 버전과 보호 상태를 동기 갱신해 늦은 응답을 차단한다. 진행 중인 동일 요청은 합치고, 성공한 동일 문장·후보 선택은 16개 이하 메모리 캐시를 사용한다. 실패는 다시 시도할 수 있다. 조건 변경 시 이전 결과의 기간·AOI를 오래된 결과로 표시하며 기존 분석 패널·레이어는 새 분석에 재사용하지 않는다.

## 지명 자료와 범위

런타임에는 외부 지오코딩 서비스나 인증키가 필요 없다. `backend/app/data/regions.json`은 테스트 fixture가 아닌, 출처를 확인한 공개 행정구역 극점의 소형 목록이다. 범용 지명 사전이나 최신 법정경계 데이터베이스는 아니다.

- **충청남도/충남**: [충청남도 2015 도정백서](https://www.chungnam.go.kr/downloadUtil.do?filename=2015_whitebook.pdf#page=47), 일반현황 인쇄 9쪽, PDF 47쪽의 극점표. 공식 서버에서 PDF 원문을 받아 렌더링하고 표를 육안 대조했다. 원문 SHA-256: `ac1fd94f3a5264c766af3cf60c9d6f1f4da11c5e11511844fe672462c49ade82`. 서단 E125°32′21″, 남단 N35°58′30″, 동단 E127°38′31″, 북단 N37°03′44″를 십진수로 바꾸고 바깥쪽 여섯 자리로 반올림한다. bbox는 `[125.539166, 35.975, 127.641945, 37.062223]`이다. **2015년 공개 극점 기준의 포함 사각형이며 최신 법정경계 폴리곤이나 정밀 측량 결과가 아니다.** 바다와 다른 행정구역도 들어간다. 기존 `[126.5,36.3,127,36.8]` 예시 사각형과 다르다.
- **경상북도 상주시**: [상주시 지역특성](https://www.sangju.go.kr/page/16483/11655.tc)의 공개 극점표. 서단 E127°47′55″, 남단 N36°14′06″, 동단 E128°20′28″, 북단 N36°39′14″. 목록에 등록된 완전한 별칭만 적용한다.
- `광주`, `중구`처럼 모호한 이름은 구분 후보를 제시한다. 후보 목록은 전체 전국 지명 목록이 아니며, 후보를 선택했더라도 검증된 좌표가 등록되지 않았다면 기존 AOI를 유지하고 수동 지정을 안내한다.
- `충남 천안시`처럼 미지원 하위 지역이 명시되면 충남 전체로 넓히지 않는다. 미지원 지명·자료 누락/손상·검색 상한 초과도 기존 AOI를 유지한다.

가로·세로 5도 이하인 검색 AOI와 25 km² 이하인 실제 픽셀 처리 AOI는 다른 상한이다. 충남 전체 사각형은 검색에 사용할 수 있으나 작은 AOI 픽셀 QA·합성·ML 추정에는 너무 크므로 작은 영역을 직접 선택하도록 안내한다. 자동으로 줄이거나 임의 중심점 주변을 택하지 않는다.

## 검증과 로컬 서버 보존

기존 서버를 임의 종료하지 않고 새로운 코드의 검증용 FastAPI를 8011에서 실행했다. 실행 중인 프론트엔드의 최신 소스에 대해 `E2E_API_BASE_URL=http://127.0.0.1:8011`로 Playwright의 실제 HTTP 요청만 그 백엔드에 전달한다. 이는 fixture가 아니다. 첨부 다운로드는 Chromium이 가로챈 탐색을 취소하므로 앱이 생성한 작업 ID/경로를 검증한 뒤, 테스트에서만 링크의 기준 서버를 8011로 바꾸어 실제 파일을 직접 저장한다. 생성 파일의 PK 헤더 검사와 저장 단언은 유지했다. TEST ONLY 응답을 쓰는 테스트는 별도 명시한다. 기존 테스트의 단언은 유지하고 공통 런타임 import만 연결한다. 최종 결과는 `TEST_REPORT.md`의 이번 절을 따른다.

선택형 검증 설정:

- `NEXT_DIST_DIR`: 기본 `.next`; 별도 production build 검증은 `.next-conditions` 사용. 기존 dev 산출물 보호용이다.
- `E2E_BASE_URL`: 기본 `http://127.0.0.1:3000`.
- `E2E_API_BASE_URL`: 미설정이면 기존 `/api` 프록시 사용. 설정하면 localhost/127.0.0.1의 별도 검증 백엔드로 실제 요청 전달.
- `E2E_OUTPUT_DIR`: 기본 `test-results`; 이번 검증은 `test-results-conditions`로 과거 결과 기록을 보존한다.

백엔드 프로세스가 변경 전 코드를 메모리에 올린 상태라면 자동입력 응답 필드가 없다. 사용자가 기존 실행 창을 종료하고 `start.cmd`로 다시 시작해야 새 백엔드 코드를 읽는다. 코드를 바꾸지 않는 재실행 절차이며 기존 서버를 이 작업에서 임의 종료하지 않는다.
