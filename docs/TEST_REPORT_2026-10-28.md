# Phase 1 검증 보고서

검증일: 2026-10-28 (Asia/Seoul)

## 목적별 기본 선택·다중 영상 비교 추가 검증

- `LIVE_STAC=1` 전체 백엔드 테스트 **33개 통과**. 실제 STAC 연결 검사와 합성 목적별 밴드 매핑·누락·중복 형식 제외·컬렉션 할당량 검사를 포함합니다. Starlette httpx 사용 중단 예정 경고 1건이 있습니다.
- Next.js 프로덕션 빌드와 TypeScript 검사 통과. 마지막 비교 문구 수정 뒤 TypeScript를 다시 검사했습니다.
- 실제 인앱 브라우저에서 충남, 2025년 7월 검색: Sentinel-2 우선 후보 14건, Landsat 추가 후보 14건을 확인했습니다.
- 침수 목적에서 green·swir16·scl 3개가 기본 선택되고 자연색 visual은 선택되지 않음을 확인했습니다. 전체 34개 선택 → 0개 해제 → 추천 3개 복원 동작을 확인했습니다.
- 비교 패널의 Sentinel-2B / Landsat-8 선택과 메타데이터 해석을 확인했습니다. 두 번째를 Sentinel-2C로 변경하면 실제 미리보기와 촬영 시각 차이(약 6일 → 5일), 구름량, 중첩 수치가 갱신됩니다. 공개 미리보기가 없는 Landsat 장면은 미제공으로 표시합니다.
- 실제 열환경 API 검색 6건에서 Landsat 3건이 우선 그룹이며 lwir11·qa_pixel·qa_radsat가 기본 선택됩니다. Sentinel-2 3건은 추가 그룹이며 thermal 누락을 표시합니다.
- 화면 증거: `docs/purpose-comparison.png`. 이번 후속 브라우저 검증은 인앱 브라우저 조작으로 수행했습니다. 업데이트한 Playwright 스크립트 전체를 재실행한 결과로 주장하지 않습니다.
- 목적별 visual은 밴드 조합 추천입니다. 표시 이미지는 제공처 미리보기이며, AOI 모자이크·목적별 픽셀 지수·침수 면적 계산 결과는 아닙니다.

## 원본 다운로드 링크 추가 검증

- 후속 사용자 요청에 따라 각 Item의 GeoTIFF/JP2 Asset을 원본 URL 그대로 노출했습니다. HTTP(S)·비용 동의 불필요 자료만 직접 링크를 표시하고, S3/요청자 비용 자료는 제한을 표시합니다.
- `LIVE_STAC=1`의 전체 백엔드 테스트 **26개 통과**. URL 보존, 비웹 스킴 차단, requester-pays 링크 제한, 실제 공개 Asset HEAD 검사 포함.
- 실제 Sentinel-2 `S2B_52SBF_20250725_0_L2A`의 green/nir/swir16 파일에 HEAD 요청: 모두 HTTP 200. 전체 파일을 내려받지는 않았습니다. 모든 검색 결과의 링크 접근 가능성을 보증하는 검사는 아닙니다.
- 실제 인앱 브라우저에서 28개 결과를 조회하고 Sentinel-2의 직접 다운로드 링크와 Landsat의 AWS 인증·요청자 비용 안내를 확인했습니다.
- Next.js 빌드·TypeScript 검사 통과. 지도 Hot Reload 시 아직 생성되지 않은 GeoJSON source를 갱신하는 오류도 준비 상태 초기화와 source 존재 검사로 수정했습니다.
- 현재 목록은 목적에 따른 후보이며 적합성이 검증된 결과만이 아니라는 설명을 명확히 했습니다. 침수 검색은 광학 보완 후보이며 SAR 검색은 아직 미지원입니다.
- AOI 추출, 다운로드 진행률/재시도 엔진, 픽셀 품질 진단은 구현하지 않았습니다.

## 후속 연결 오류 복구

- 브라우저에 수정 전 MapLibre 코드가 남아 있었고, 3000/8000 서버가 종료된 상태임을 확인했습니다.
- `scripts/start-local.mjs`와 `start.cmd`를 추가했습니다. 두 서버를 함께 실행하고 `/api/health` 성공까지 확인하며, 중복 포트 사용 시 기존 프로세스를 종료하지 않고 안내합니다.
- 최신 코드로 서버를 실행하고 사용자의 실제 인앱 브라우저를 새로고침했습니다. 지도 초기화와 추천 기능이 정상 복구되었습니다.
- 실제 인앱 브라우저에서 충남 예시 AOI, 2025-07-01~2025-07-31 검색으로 28개 영상과 촬영 범위·메타데이터 표시를 확인했습니다. 합성 응답을 사용하지 않았습니다.
- 복구 화면: `docs/restored-app.png`. 이번에는 사용을 계속할 수 있도록 서버를 실행 상태로 유지했습니다.

## 실제 API 검증 증거

실제 `/collections` 응답에서 `sentinel-2-l2a`, `landsat-c2-l2`의 존재를 확인한 후 구현했습니다.

AOI `[126.5, 36.3, 127.0, 36.8]`, 2025-07-01~2025-07-31 검색 결과의 예:

| 실제 Item ID | 촬영 시각 UTC | 센서 | 장면 구름량 | 해상도 메타데이터 |
|---|---|---|---|---|
| `S2B_52SBF_20250725_0_L2A` | 2025-07-25T02:27:32.626000Z | msi | 1.197259% | 10 / 20 / 60 m |
| `S2C_52SBF_20250730_0_L2A` | 2025-07-30T02:27:52.286000Z | msi | 64.629459% | 10 / 20 / 60 m |
| `LC08_L2SP_116035_20250731_02_T1` | 2025-07-31T02:11:20.419737Z | oli, tirs | 50.64% | 30 / 100 m |

각 컬렉션에서 3개씩 원본 Item `self` 링크를 GET하여 ID·촬영 시각·센서·구름량·geometry가 앱 응답과 정확히 일치함을 assertion으로 확인했습니다. 해상도·중첩률·처리 수준이 제공되는지도 검사했습니다.

STAC 페이지네이션 검사는 2025-05-01~2025-07-31 Sentinel-2 검색으로 30개 고유 Item과 초과 결과 표시를 확인했습니다. 초기 테스트의 7월 한 달에는 실제 Sentinel-2 Item이 14개였으므로 테스트 기간을 넓혔습니다. 결과 수를 조작하지 않았습니다.

## 발견하여 해결한 사항

1. 제한된 실행 환경의 가상환경 생성/네트워크/소켓 제한: 허용된 실행 권한에서 설치·테스트 완료.
2. Windows Turbopack의 CSS 처리 자식 프로세스 연결 오류: Next.js Webpack 모드로 변경.
3. MapLibre 구버전 XSS 취약점: 감사 결과 수정 범위에 해당하는 6.5.0으로 고정, 취약점 0건 확인.
4. MapLibre ESM default export 제거: named module import로 변경, worker URL과 로컬 배포 파일 준비.
5. 생성 시 `maxBounds` 설정으로 발생하는 지도 행렬 초기화 오류: 생성 옵션에서 제거. 서버의 AOI 좌표 제한은 유지.
6. Landsat 처리 수준의 제공처별 필드 차이: 원본 `landsat:correction`의 `L2SP`를 표시하도록 정규화 보완.
7. 개발 서버가 남긴 `.next/dev` 타입 캐시 충돌: 프로젝트 내부 생성 캐시만 정리 후 빌드 성공. README에 복구 방법 기록.
8. 다수 촬영 범위가 겹쳐 배경을 가리는 문제: 비선택 영상 면 투명도를 낮추고 선택 영상 경계 강조.

## 남아 있는 제한

- 테스트 클라이언트에서 Starlette의 httpx 사용 중단 예정 경고 1건이 발생합니다. 현재 테스트 24개는 통과하며 런타임 API 오류가 아닙니다. 후속 의존성 업데이트 시 전환 검토가 필요합니다.
- 일부 Landsat 썸네일은 `s3://` requester-pays 경로여서 브라우저 미리보기를 제공하지 않습니다. 공개 HTTP(S) thumbnail Asset만 표시합니다. Asset 다운로드 접근 검증은 Phase 2 범위입니다.
- OpenStreetMap·썸네일·STAC 제공처의 향후 가용성은 보장하지 않습니다. API 실패를 결과 없음이나 가짜 데이터로 대체하지 않습니다.
- 배경지도는 지도 서비스를 사용하고 실제 위성 RGB 래스터를 지도 타일로 렌더링하지 않습니다. Phase 1 지도에 나타나는 영상 레이어는 실제 STAC Item의 촬영 범위입니다.
- 실제 유효 관측률, AOI 구름량, 그림자, NoData, 전후 영상 비교 가능성, 과학적 분석 적합성은 검사하지 않았습니다.
