## 확보 상태와 실행 게이트

장면 선택, 검색 메타데이터 수신, 제공처 로그인, 미리보기, Range 접근 확인, 링크 목록.txt 생성, 원본 전체 응답 수신은 별개다. `ManagedAssetAccess`의 동일 장면/Asset 전체 수신이 끝난 경우에만 확보 기록을 만든다. 중단·오류를 완료로 바꾸지 않는다. 외부 직접 링크에서 받은 파일의 완료는 앱이 알 수 없다.

확보 기록은 브라우저 응답 완료를 뜻한다. OS 디스크 저장·파일 현존·서버 원본 캐시를 보증하지 않는다. 서버가 브라우저 파일을 분석하는 것도 아니다. 실제 처리 시 기존 서버는 canonical Item/밴드·범위/정책을 다시 검사하고 원본의 필요한 범위를 읽는다. 새 업로드/대용량 원본 캐시 엔진은 추가하지 않았다.

UI에서 선택한 원본의 전체 수신과 필수 밴드 선택이 없으면 픽셀 QA·합성·ML·NDVI 실행을 막는다. 메타데이터 비교/A2는 파일 확보와 별도로 가능하다. 단일 품질/관측 합성은 기존 엔진의 red/nir/green/scl을 필요로 하므로 NDVI 기본 세트에 green이 없으면 수집에서 추가 선택·확보하도록 설명한다. 선택된 합성 후보도 같은 조건을 만족해야 한다.

브라우저의 과거 수신 기록을 인증 증거로 사용하지 않는다. 제공처 인증/권한/유효성·Item·밴드·범위·보정·작업 한도는 기존 서버가 검증한다. 자격증명·재제공 승인·requester-pays 설정은 변경하지 않았다.

## 복원과 소유권

- 같은 탭의 `sessionStorage`에는 버전/크기 제한이 있는 작업 메타데이터만 보관한다. 목적·조건/수동 수정 출처·bbox·선택·밴드·수신 기록·품질 수치 기록·설정·작업 ID를 복원한다.
- 토큰/비밀번호/쿠키/서명 query URL/receipt·실행 계획·확인 digest·래스터 이미지/ZIP 바이트는 저장하지 않는다. 정상 행정경계의 링을 일반 배열 상한으로 잘라 잘못된 경계로 복원하지 않는다.
- 복원 전에는 입력을 잠가 사용자 입력과 복원 응답의 경합을 막는다. 진행 중/미확정 문장은 자동 확정하지 않고 재시도·직접 확인을 요구한다. 새로고침 자체는 유료 AI·검색·다운로드·처리를 다시 시작하지 않는다.
- 실제 파일과 NDVI 메모리 ZIP/지도 픽셀은 새로고침 후 복원할 수 없다. 저장된 QA는 검사 당시 기록으로 표시한다. 합성/ML은 작업 ID로 상태만 조회하고 소유권·서버 보관 상태가 확인될 때 산출물 링크를 제공한다.
- `work_sessions.py`의 별도 서명 HttpOnly/SameSite=Strict 브라우저 세션 쿠키로 합성/ML 계획·실행·조회·취소·다운로드 소유권을 검사한다. 브라우저 프로필 세션이며 사용자 계정 인증/Supabase가 아니다. 쿠키를 localStorage/sessionStorage에 쓰지 않으며 Max-Age 영구 쿠키로 만들지 않는다. 서버 키는 메모리만, 유효성은 최대8시간이다.
- 작업/계획·ZIP의 기존 서버 메모리15분 보관은 유지한다. 서버 재시작·만료·다른 세션이면 조회 불가를 안내한다. 다중 worker/공개 다중 사용자 운영을 완성한 것은 아니다.
- 페이지 이동은 컴포넌트를 유지한다. 새로고침 시 기존 작업 조회만 재개하며 새로운 작업을 POST하지 않는다. 조건/선택/밴드/설정이 달라지면 기존 지도/계획/확인을 비우고 과거 작업·산출물을 이전 조건으로 표시한다. 명시 취소를 제공한다.
