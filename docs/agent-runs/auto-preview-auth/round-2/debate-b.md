# Debater B — 회차 2 독립 최종 검토

## 판정과 장점

사용자 목표는 **부분 충족**이다. 가시 장면의 자동 미리보기와 공유 큐·동시 제한, 명시 원본 다운로드가 구현되어 반복 클릭과 불필요한 요청을 줄이도록 설계됐다. 리더의 별도 실제 앱 서버 확인에서 Kakao 지명 검색은 `resolved`, 후보 1건이었고 NASA 공개 browse는 preview-only 요청으로 70,963바이트를 수신했으며 원본 asset 요청은 0이었다. 이는 공개 이미지와 서버 경로의 실연결 근거이지 브라우저 자동 표시나 NASA 로그인·원본 접근의 증거는 아니다.

## 폐기와 UI

`earthdata_store.py`의 보호된 journal 기록·재독 검증이 성공하면 DB 삭제가 실패해도 해당 SID의 재시작 후 복원을 차단한다. QA가 관련 fixture와 별도 프로세스 검사를 실행했다. 이 보장은 유효한 기록이 보존되고 복원 시 확인되는 조건에 한한다. 모든 지속 쓰기가 실패하면 현재 프로세스의 차단과 쿠키 보존·명시 재시도만 가능하고 재시작 후 복원 가능성이 남는다. 저장소 복구·확인 가능한 격리와 NASA 측 철회는 별개 조치이며 영구 폐기를 주장할 수 없다.

기본 메모리 모드와 명시 opt-in은 실제 ACL 및 계정 검증이 없는 현재 상황에서 적절하다. 이전 포맷을 조용히 복원하거나 삭제하지 않고 격리를 요구하는 점도 유용하다. 기본값 변경 자체가 기존 grant 폐기는 아니다. `EarthdataConnection.tsx`는 503의 폐기 미확인을 유지하고 재시도와 현재 탭·다른 탭 큐 무효화를 지원한다. 최종 코드에서 다른 탭의 확인된 폐기 성공 신호가 경고를 해제함을 확인했으며, 전달과 새로고침 보존은 localStorage 가용성에 의존한다. 실제 브라우저 동작은 아직 확인되지 않았다.

## 증거와 남은 조건

Auth 담당의 전체 백엔드 **359 passed / 17 skipped**는 마지막 응답 메타데이터 변경 전 결과다. 그 후 독립 QA가 관련 **68 passed / 1 skipped**와 TypeScript 통과를 확인했다. 테스트 grant는 fixture이고 DPAPI 테스트의 ACL 설치는 mock이며 실제 ACL 준비는 skip이다. 프런트 VM fixture와 Playwright 수집도 브라우저 실행이 아니다. production build와 E2E는 `spawn EPERM`으로 미완료다. 허용된 환경에서 실제 ACL·재시작, 브라우저 가시성·동시성·503/다른 탭·다운로드 및 production build 검증이 필요하다. 전원 손실과 저장소 롤백 내구성도 입증되지 않았다.

NASA 실제 로그인·갱신·인증 원본은 미검증이고 USGS/CDSE 신규 원본 인증은 미연결이다. 기존 검색은 3개 제공처·4개 컬렉션으로 전체 위성 연결이 아니다. 기존 운영 서버에는 새 코드와 Kakao 설정이 아직 반영되지 않았으며 지도 카메라 이동도 미검증이다. 재시작과 실계정 검증은 운영 작업 상태 및 권한이 확보된 뒤 별도로 확인해야 한다. 본 의견은 독립 초기 검토이며 제품·테스트 수정, 직접 테스트, 위임이나 새 구현 루프는 하지 않았다.

## A 의견에 대한 수용

A의 조건부 폐기 보장, 명시 opt-in, 503 처리와 검증 보류 판단에 동의하며 실질적 이견은 없다. 남은 개선점은 허용된 환경에서의 production build·실제 브라우저·ACL 및 재시작 검증, 저장소 실패 복구와 제공처 철회 확인, 실제 NASA 인증·원본 접근 및 USGS/CDSE 연결 검증, 운영 서버 설정 반영과 지도 동작 확인이다. 전원 손실·저장소 롤백 내구성도 별도 검증이 필요하다. 세 번째 구현 사이클은 진행하지 않는다.
