# Analyst — 회차 2 최종 판정

## 요구별 상태

- **자동 미리보기·명시 다운로드: 구현 완료, 사용자 동작 검증 대기.** 가시 장면의 공유 큐·동시 제한과 preview-only 요청, receipt 만료 시 제한된 복구를 구현했다. 원본 다운로드는 사용자 동작으로 시작한다. 실제 브라우저 자동 표시와 다운로드 경합은 미검증이다.
- **로그인 유지: 부분 완료.** NASA 저장은 `EARTHDATA_PERSIST_SESSIONS=1` 명시 선택 시에만 사용하며 기본은 재시작 후 해제되는 메모리 모드다. 구형 저장소는 자동 복원하지 않는다. 실제 ACL·계정·갱신 검증은 대기다.
- **제공처 통합: 부분 완료.** 기존 검색은 3개 제공처·4개 컬렉션이다. USGS/CDSE 신규 원본 인증은 미연결이고 NASA 앱 설정과 실제 인증 원본 접근도 미완료다.
- **Kakao 및 실제 공개 이미지: 제한된 실연결 확인.** 검증용 앱의 Kakao 검색은 HTTP 200, resolved 후보 1건, camera-only였다. NASA 공개 browse는 preview-only 검사에서 원본 assets 0, 이미지 HTTP 200·70,963바이트를 확인했다. 이는 지도 이동, 브라우저 렌더, NASA 로그인이나 인증 원본의 성공이 아니다.

## 보안과 검증 판정

양쪽 최종 상호 응답은 조건부 해결과 잔여 제한에 합의했고 실질적 이견은 없다. 유효한 v2 폐기 journal이 성공적으로 기록·보존되고 복원 시 검사되면 DB 삭제 실패 후에도 해당 SID 복원을 차단한다. 모든 지속 쓰기가 실패하면 현재 프로세스 차단과 cookie 보존·명시 재시도는 가능하지만 재시작 후 영구 폐기는 보장할 수 없다. 권한 복구, 확인 가능한 저장소 격리와 NASA 측 철회는 별도 조치다. 전원 손실·저장소 롤백 내구성도 미검증이다. 보안 담당은 다른 탭의 성공 신호 처리에 대한 이전 지적을 최종 코드 확인 후 철회했다. 탭 간 전달은 localStorage 가용성에 의존하며 브라우저 검증은 남아 있다.

독립 QA의 최종 핵심 테스트는 **68 passed / 1 skipped**, TypeScript 통과다. 담당자의 전체 **359 passed / 17 skipped**는 마지막 작은 응답 메타데이터 수정 전 결과다. OAuth grant는 fixture이며 실제 DPAPI 테스트도 ACL 설치는 mock했다. Playwright 수집과 VM fixture는 실제 브라우저 실행이 아니다. production build와 E2E는 `spawn EPERM`으로 미완료다.

## 리더 인계: 남은 조건

1. 허용된 환경에서 production build와 실제 브라우저 E2E를 수행해 가시성·동시성·503/다른 탭·다운로드를 확인한다.
2. 실제 Windows ACL 및 서버 재시작, 폐기 실패 복구와 저장소 격리를 검증한다. 모든 쓰기 실패를 폐기 성공으로 표현하지 않는다.
3. NASA 앱 등록 후 실제 로그인·갱신·인증 원본 권한을 확인하고, USGS/CDSE는 별도 연동과 계정·제품 검증이 필요하다.
4. 기존 운영 서버는 진행 중 분석·다운로드 확인 답변 대기로 유지 중이다. 반영 가능할 때 새 코드와 Kakao 설정을 적용하고 지도 동작을 확인한다. 검증용 8015만 확인 후 종료됐다.

**사용자 보고 문안 제안:** “자동 미리보기와 선택형 NASA 로그인 유지 기능을 구현했고, 별도 검증 서버에서 Kakao 지명 조회와 NASA 공개 미리보기 수신을 확인했습니다. 운영 서버 반영과 실제 브라우저·로그인·원본 접근 검증은 아직 남아 있으며 USGS/CDSE 원본 인증은 연결되지 않았습니다.”

최종 두 번째 회차 판정이며 추가 구현 루프는 진행하지 않는다.
