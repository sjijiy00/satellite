# 단계1 기획자

docs/agent-runs/auto-preview-auth/brief.md와 공통 프로젝트 지침을 읽는다. 실제 구조를 짧게 조사해 이번 사용자 요구를 구현 가능한 범위로 계획한다. 제품/환경 파일 수정 금지. 결과는 이 폴더 planner.md 하나에 작성.

중점: ProviderPreview/useProviderAccess의 수동 검사 원인, 120초 receipt와 미디어 세션 재시작 문제, Earthdata OAuth 8시간 메모리 한계, USGS/다른 제공처 인증의 실제 제약, 서버 환경 전달, Kakao 설정 반영. 공식 문서 근거가 필요한 인증은 primary source를 확인한다. 제공처 모두 연결했다는 주장을 만들지 않는다.

출력: 사용자 요구 충족 범위/미충족 조건, 우선 구현안, API/프런트 계약 제안, 단계2 역할별 파일 소유권, 의미 있는 테스트/브라우저 검증, 보안 핵심, 미결정 선택. 1000단어 이하. 한 번 조사 후 보고하고 대기. 진행을 패널에 짧게 표시.
