# 사용자 요청과 공통 계약

사용자는 backend/.env에 Kakao API를 입력했다. 제공처 미리보기를 별도 '미리보기 접근 확인' 클릭 없이 보고 싶어 한다. 한 번 제공한 로그인 설정/연결을 서버에서 유지·갱신해 미리보기와 다운로드를 편리하게 쓰고, 여러 제공처·위성을 같은 웹사이트에서 이용하려 한다.

루트 AGENTS.md, 최신 README/TEST_REPORT의 현재 범위, 담당 하위 지침과 실제 코드를 읽는다. 환경은 Windows PowerShell + psmux의 기존 Codex 세션이다. Claude로 표현하지 않는다. 스킬은 실제 가능한 필요한 것만 적용한다. 새 분석 엔진이나 임의의 전세계 위성 연결을 만들지 않는다.

화면 출력은 '배정 받은 업무 | 역할 | 과제', '업무 진행 중 | 역할 | 현재 작업 한 줄', '업무 완료! | 역할 | 결과 한 줄' 형식이다. 상세 과정/사고는 출력하지 않는다. 장기 작업은 의미 있는 단계 전환 때 짧게 상태를 보여준다. 실제 파일/검증 근거를 역할별 결과 파일에 기록한다. 차단되면 원인과 필요한 조건을 기록하며 완료로 과장하지 않는다.

제품 변경 목표:
- 화면에 보이는 제공처 미리보기는 자동 로드. 중복/동시 요청/스크롤 밖 대량 다운로드를 제어하고 재시도는 명시적으로 제공. 인증 변경·장면 변경·늦은 응답 격리와 미디어 세션 만료 복구.
- 원본 전체 다운로드는 사용자 동작으로만. 미리보기 자동로드로 원본을 받거나 비용 동의/requester-pays를 우회하지 않음.
- 공식 인증·갱신·폐기를 존중하는 제공처별 연결. 개인 비밀번호/세션 쿠키를 범용 .env로 복제해 모든 제공처에서 쓰지 않음. .env에는 사용자가 의도한 서버 설정/공식 자격증명만. 사용자 로그인 후 발급된 토큰은 사용자별 서버 보관을 우선 검토. 무기한 연결 보장 불가를 정확히 표시.
- Kakao 실제 키/GEOCODER_ENABLED의 존재 여부와 설정 인식만 안전하게 점검. 비밀값은 로그/출력/리포트/브라우저/명령 인자에 넣지 않음. 사용자의 기존 .env 값 보존.
- 현재 지원 3개 제공처·4개 컬렉션과 다른 미연결 후보를 구별. NASA/USGS/Copernicus 공식 문서로 실현 가능한 인증만 구현. 미설정/미검증 경로 명확히 보고.
- 기존 분석·선택·단일 검색 흐름 보호. fixture와 실연결을 구별. 명령·종료코드·실제 실패 기록.

최대 2회: 기획→리더 조정→필요 역할 구현/QA/보안→두 토론인 상호 검토→분석관→리더. 회차2는 남은 문제만, 세 번째 수정 사이클 없음.

공통 보고 폴더: docs/agent-runs/auto-preview-auth/round-1/ . 각 역할은 자기 보고 파일과 지정된 소유 파일만 수정한다. 다른 세션의 코드/문서를 덮어쓰지 않는다. 보고 완료 후 추가 작업을 스스로 만들지 않는다.
