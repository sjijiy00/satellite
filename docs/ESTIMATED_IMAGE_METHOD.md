# 선택형 ML 추정영상 방법과 한계

기준일: 2026-10-29. 구현 버전 `s2-local-ridge-estimate-2026-10-29.1`. 이 기능은 **목표일에 가려진 픽셀의 표면반사도를 예측**한다. 구름 아래에서 실제로 관측한 값을 복원하거나 그날의 참값을 증명하지 않는다. 기존 [여러 날짜의 실제 관측 선택 합성](../README.md)은 모델 추정 없이 실제 한 장면의 픽셀만 고르는 별도 기능이다.

## 입력과 적용 범위

- 식생 **한 시점/기간 상태**만 지원한다. 전후 변화, 홍수·산불의 사건 당시 상태, 열환경, SAR·다중 센서 결합에는 사용하지 않는다.
- 사용자가 확정한 작은 AOI와 UTC 기간 안에서 공개 Sentinel-2 L2A 목표 Item 1개와 같은 위성 플랫폼·처리 기준선의 참조 Item 1~3개를 사용한다. 참조 관측은 목표와 다른 날이며 날짜 차이는 최대 14일이다. 기간 길이는 최대 31일이다. 현재 앱의 다른 검색 조건이나 임의 새 날짜를 자동 추가하지 않는다.
- 보정 근거가 확인된 적색 B04, 근적외선 B08, 녹색 B03 표면반사도와 SCL/NoData를 원본 COG에서 실제 범위 읽기로 검사한다. 공개 허용 URL·Header·scale/offset·같은 플랫폼/기준선 검사를 기존 A3/A4 경로와 공유한다. SCL 분류는 [정책](../backend/app/pixel_policy.py)의 4·5·6만 유효로 취급한다. 분류 오차 가능성은 남는다.
- AOI 25 km², 공통 20 m LAEA 격자 100,000셀, 원본 파일/전송/요청/시간/동시 작업 등은 기존 A3 상한을 따른다. 이번 추정의 추가 운영 상한은 후보 4장면, 31일 기간, ZIP 4 MB다. 압축률·실행 시간은 사전 보증하지 않는다.

## 실제 계산

1. 목표일과 한 참조일 모두 SCL/NoData에서 유효하고 적색·근적외선·녹색 반사도가 유한한 **같은 출력 격자 위치**를 학습 쌍으로 만든다. 목표일의 맑은 반사도 3개가 지도학습 정답이고 참조일의 반사도 3개가 입력이다. 가린 목표일 픽셀은 학습·검증 정답으로 쓰지 않는다.
2. 입력/출력을 밴드별 평균과 표준편차(하한 `1e-6`)로 표준화한다. 절편은 벌점을 주지 않는 결정론적 다중 출력 ridge 회귀를 NumPy 선형식 `(XᵀX + αI)⁻¹XᵀY`로 적합하며 `α=1.0`이다. 이는 AOI마다 새로 학습하는 국소 선형 모델이다. 외부 유료 모델이나 범용 사전학습 신경망을 호출하지 않는다.
3. 관측 쌍을 격자의 **2×2 연속 공간 사분면**으로 나누고 각 사분면을 한 번씩 보류하는 4-fold 검증을 한다. 최소 짝픽셀 400개, 사분면당 보류 픽셀 40개, 각 fold 학습 픽셀 200개가 필요하다. 밴드별 MAE·RMSE·절대오차 90백분위와 NDVI MAE를 계산한다. 같은 보류 픽셀에 참조일 반사도를 그대로 목표일로 복사한 단순 기준선도 계산한다.
4. 세 밴드 평균 MAE가 단순 복사 기준선보다 **최소 5% 작고**, 각 밴드 MAE가 그 밴드 기준선의 **1.05배 이하**이며, NDVI MAE가 기준선 이하일 때만 해당 참조일 모델을 통과시킨다. 기준선 평균 MAE가 0이거나 검증/NDVI 계산이 불가능하면 통과하지 않는다. 이것은 앱의 보수적 **운영 게이트**이며 보편적 과학 정확도 기준이 아니다.
5. 통과한 참조일을 목표일과의 절대 날짜 차이 → 취득시각 → 컬렉션·Item ID 순으로 결정론적으로 평가한다. 목표일의 실제 유효 픽셀은 **한 값도 대체하지 않는다**. 목표일에 가리고 참조일에는 유효한 위치만 예측 후보가 된다. 참조 입력은 학습 범위의 밴드별 최소/최대에 폭의 5% 여유를 둔 안에 있어야 한다. 예측 출력은 유한하고 0 이상이며 학습 목표 범위의 최소/최대에 폭의 10% 여유를 둔 안에 있어야 한다. 먼저 통과한 참조일이 선택한 위치를 뒤 후보가 덮지 않는다. 조건에 맞지 않는 곳은 결측으로 남긴다.
6. 계획 단계에서 원본 파일 ETag, 모델 지문, 검증 지표, 면적과 입력 조건을 묶어 확인용 digest를 만든다. 사용자가 계획을 확인한 후 실행 단계에서 원본 Item/ETag와 학습·검증을 다시 수행해 digest가 달라지면 중단한다. queued/running/succeeded/failed/cancelled 상태와 취소는 기존 제한된 작업 경로를 사용한다.

## 출력과 출처

완료 ZIP에는 `target_observed.tif`(목표일 실제 유효 반사도만), `estimated_only.tif`(모델 추정만), `estimate_with_observed.tif`(두 종류를 한 파일에 배치하되 종류를 분리해 읽어야 함), `pixel_status.tif`(0 미해결/영역 밖, 1 목표일 실제 관측, 2 추정), `donor_index.tif`(추정 픽셀의 1부터 시작하는 참조 Item 번호), `donor_date.tif`(추정 픽셀의 참조 UTC 날짜), `manifest.json`이 있다. 날짜 TIFF는 1970-01-01부터 UTC 일수, NoData `-2147483648`; 연속 밴드는 float32 NoData `-9999`다. CRS·transform·밴드 설명을 GeoTIFF에 보존하고 생성 후 Rasterio로 다시 연다.

Manifest에는 AOI·기간·목표/참조 Item·취득일·모델 버전/계수·학습/보류 픽셀·밴드별 오차·기준선·마스크/격자·관측/추정/잔여 면적·파일 SHA-256을 기록한다. 인증/서명 URL과 Item URL의 쿼리는 기록하지 않는다. 지도에는 목표일 실제 픽셀과 ML 추정 픽셀의 **서로 다른 거짓색 미리보기 레이어**를 제공한다. 색은 정량 반사도가 아니며 GeoTIFF와 `pixel_status.tif`가 분석 기준이다. 목표일 실측 날짜와 참조일 관측 날짜를 합쳐 단일 실측 날짜로 표시하지 않는다.

## 검증이 말해 주는 것과 말해 주지 않는 것

- 공간 사분면 보류 결과는 **맑은 목표일 픽셀**에서의 국소 일반화 시험이다. 학습과 보류가 같은 장면·지역 내에 있으므로 완전히 독립된 지역/계절 검증도 아니다. 원격탐사 장면의 공간 자기상관 때문에 독립성은 제한된다.
- 두꺼운 불투명 구름 아래 목표일의 실제 정답은 관측할 수 없다. 따라서 보류 영역 MAE/RMSE·90백분위는 가려진 픽셀의 정확도나 보증 구간이 아니다. 가림 영역이 맑은 영역과 토지피복·생육 단계·사건 상태가 다르면 오차가 커질 수 있다.
- 참조일과 목표일 사이의 실제 변화, SCL의 구름/그림자 오분류, 원본 보정·기하 정합 오차가 모델에 섞일 수 있다. NDVI 검증 지표가 낮아도 개별 객체 판독, 변화 분석 또는 의사결정 적합성을 보증하지 않는다.
- 충분한 짝픽셀이나 기준선 개선이 없으면 `blocked`로 반환하고 구름 아래를 채우지 않는다. 실제 관측 기반 합성과 추정 모드는 별도 선택이며 어느 쪽도 불가능하면 빈 영역을 유지한다.

## 현재 검증 상태

[`backend/tests/test_cloud_estimate.py`](../backend/tests/test_cloud_estimate.py)의 테스트 전용 32×32 고정 TIFF는 계획→실행→ZIP 재열기, 실측 불변/추정/미해결/출처 날짜, 학습 부족·기준선 미개선·잘못된 기간/목적/제품 차단 및 서명 URL 비노출을 확인한다. 이 fixture는 서비스가 외부 자료에 접근하지 못할 때 대체 결과로 사용하지 않는다. [`backend/tests/test_cloud_estimate_live.py`](../backend/tests/test_cloud_estimate_live.py)는 알려진 공개 Sentinel-2 두 Item을 제공처에서 실제 조회하여 계획→실행→ZIP 파일 저장·재열기를 검증했다. 브라우저 E2E는 실제 `/search`부터 선택·실행·다운로드까지 검증했다. 이 한 사례의 성공은 불투명 구름 아래 참값 정확도 검증이 아니다. 전체 회귀 실행 상태와 재현 조건은 [최신 테스트 보고](../TEST_REPORT.md)를 확인한다.

## 방법 설계의 연구 참고

- [AllClear: A Comprehensive Dataset and Benchmark for Cloud Removal in Satellite Imagery (NeurIPS 2024)](https://proceedings.neurips.cc/paper_files/paper/2024/file/60095e1d7ebb292dbba93c4d8f7b2463-Paper-Datasets_and_Benchmarks_Track.pdf): 다양한 구름 제거 접근의 검증 문제를 다룬다. 이 앱의 국소 ridge가 논문 모델의 성능을 달성한다는 뜻은 아니다.
- [Roberts et al., Cross-validation strategies for data with temporal, spatial, hierarchical, or phylogenetic structure (Ecography 2017)](https://doi.org/10.1111/ecog.02881): 공간적으로 이웃한 표본을 무작위로 나누면 검증 오차가 낙관적일 수 있어 연속 공간 보류를 사용했다. 이 앱의 2×2 분할만으로 지역 외 일반화를 증명하지 않는다.
- [Canty et al., Automatic radiometric normalization of multitemporal satellite imagery (Remote Sensing of Environment 2004)](https://www.sciencedirect.com/science/article/pii/S0034425704001208): 날짜 간 방사 특성 변환의 참고다. 실제 지표 상태 변화는 단순 선형 변환으로 제거할 수 없다.
