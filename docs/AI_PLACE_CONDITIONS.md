## 현재 동작

기존 OpenAI Responses API·strict schema·수동 폼·추천/검색 API를 확장했다. AI 성공은 조건 전체 확정이 아니다. UI에 목적 추출, 기간 검증/충돌, 지명 원문, 위치 검색, 사용자 AOI 확정을 각각 표시한다.

`2026년 7월 연천군의 지표면온도를 분석하고 싶어`의 검증된 AI 응답은 목적 `thermal`, 대상 원문 `지표면온도`, 기간 UTC `2026-07-01`~`2026-07-31`, 지명 원문 `연천군`이다. 목적·기간은 기존 단일 폼에 반영한다. 직접 수정한 목적/날짜/분석 형태는 우선 보존하며 충돌과 명시 재적용을 제공한다. 지명 문자열은 실제 입력의 부분문자열인지 서버에서 검증한다. 좌표·경계·위성 사양·영상 존재·품질은 AI 스키마에 없다.

위치 확인은 **사용자가 선택한 Kakao 서버 키 방식**이다. Nominatim 공개 서비스는 이번 제품에 연결하지 않는다. 현재 Kakao 키·활성화 설정이 없어 실제 위치 검색은 비활성이다. 이 상태에서도 AI 목적/기간 제안과 `연천군 인식됨 · 위치 검색 미설정`은 표시하고 수동 지도·좌표 입력은 유지한다. **지금 실제 Kakao 결과로 연천군 카메라 이동까지 검증됐다고 주장하지 않는다.** 해당 전체 흐름은 모의 응답으로 검증했다.

## 설정과 제공 범위

Kakao Developers에서 사용자가 앱을 생성/선택하고 현재 카카오맵 사용 설정·권한·쿼터·이용 조건을 직접 확인한 뒤 **REST API 키**를 서버 전용 `backend/.env`에 입력한다. JavaScript 키/어드민 키/OpenAI 키와 다르다. 키를 채팅·브라우저·`NEXT_PUBLIC_*`·URL에 넣지 않는다.

```dotenv
GEOCODER_ENABLED=1
KAKAO_LOCAL_REST_API_KEY=
```

위 예시는 빈 변수명 안내다. 실제 키를 예시 파일에 넣지 않는다. 이번 작업은 사용자의 `.env`를 수정하지 않았으며 계정 생성·키 발급·유료 사용 동의를 대신하지 않았다. `scripts/server-env.mjs`는 정해진 `backend/.env`의 이 두 변수만 기존 서버 허용 목록에 추가한다. 프로세스 환경이 우선하고 frontend/build에는 `KAKAO_*`, `GEOCODER_*`를 전달하지 않는다. 설정 변경 후 진행 중 작업을 확인하고 해당 프로젝트만 재시작한다.

제공 범위는 대한민국의 Kakao 주소 검색에서 반환하는 **REGION 행정 지명**이다. 시·도, 시·군·구, 읍·면·동 이름/상위 지역/코드/중심점을 응답에 있는 대로 사용한다. 명칭은 Kakao 응답 기준이며 정부 법정경계를 검증했다는 뜻이 아니다. 도로·건물·POI를 행정구역 대신 선택하지 않는다. 해외·자연 지형·옛 군 경계·전국 모든 행정명의 완전성은 지원/보장하지 않는다. 조회 0건은 지명의 부존재 판정이 아니다.

기존 `regions.json`의 충남·상주·영천 자료는 출처가 있는 **별도 로컬 카메라 참고 자료**로 유지한다. 영천군은 영천시와 통합된 옛 행정명이라는 안내와 기존 2025년 8월 동작을 보존한다. 미등록 지명을 상위 행정구역이나 임의 좌표로 대체하지 않는다.

## API와 상태

- 기존 `POST /request/interpret`, `interpretation_mode=ai`를 유지한다. `extraction`에 목적·근거, 분석 대상 원문, 기간·분석 형태 근거, `places`, 불확실성을 보존한다. 미등록 지명은 `lookup_required`이고 `mentioned_text`를 잃지 않는다. AI 호출 실패는 수동 값 보존/명시 오류이며 규칙 성공으로 위장하지 않는다.
- `GET /places/config`: 준비 상태·누락 **설정 이름**·제공처·상한만 반환한다. 키는 반환하지 않는다.
- `POST /places/search`: `{text, place}`만 받는다. 원문 포함 여부·길이·허용 문자를 검사하고 URL 필드는 거부한다. 키는 서버에서 고정된 `dapi.kakao.com`의 Authorization 헤더에만 전달한다. 리다이렉트·자동 재시도·임의 URL 요청을 하지 않는다.
- 결과는 `resolved`, `ambiguous`, `no_results`, `not_configured`, `authentication_failed`, `limited`, `timeout`, `invalid_response`, `failed`, `needs_confirmation`을 구분한다. 명칭·행정 단계·상위 지역·중심점·출처·UTC 확인 시각을 화면의 일시 상태로 보존한다.
- 한 요청 8초, 응답 512 KiB, 1페이지 30건, 동시 1개·분당10회·프로세스당100회로 제한한다. 다음 페이지가 있으면 `truncated=true`/후보 확인으로 표시하며 한 결과를 확정하지 않는다. “중구/광주”는 상위 지역을 포함한 후보를 사용자가 선택해야 한다.
- 입력 debounce/blur는 기존 무료 규칙 해석만 한다. 외부 위치 조회는 `AI로 문장 해석`에서 검증된 원문을 받았을 때 또는 `위치 확인` 버튼에서만 한다. AI 성공 추출은 기존 캐시를 재사용하되 Kakao 위치 결과는 서버 캐시·DB·localStorage·로그·다운로드 manifest에 저장하지 않는다. 후보 선택으로 AI를 다시 호출하지 않는다.

Kakao 응답 중심점으로 MapLibre 카메라만 이동한다. 중심점 주변 사각형·행정 경계·분석 AOI를 생성하지 않는다. 기존 수동 AOI가 있으면 좌표를 유지하고 기존 AOI 유지/새 선택을 확인한다. 늦은 AI 응답은 수동 필드 출처를 확인하고, 늦은 위치 응답은 문장 세대·지도/AOI 수정 세대를 확인한다. 사용자의 지도 조작 뒤 도착한 위치는 자동 적용하지 않고 명시 이동 버튼으로 확인한다. 새 문장·다른 후보·취소는 이전 응답을 폐기한다.

AOI 확정 후 검색은 `FormConditions`의 목적·UTC 기간·수동 좌표를 기존 추천/검색 경로에 전달한다. 분석 장소 이름은 지도 안내이며 검색 AOI를 대체하지 않는다. 검색·픽셀 처리를 AI 해석만으로 실행하지 않는다. 열환경은 기존 Landsat 열적외선 규칙을 사용하고 Sentinel-2를 직접 지표면온도 센서로 바꾸지 않는다. 기온과 지표면온도는 별개라는 안내를 유지한다.

연도 없는 월·상대 날짜·지난 장마·사건 기준일 없는 전후 비교·일대/주변·여러 지명은 자동 확정하지 않는다. 명시적 연도/월 또는 UTC 기간, 정확한 장소와 사용자의 AOI/사건 기준을 추가로 확인한다.

## 공식 근거와 실제 검증 경계

- [Kakao Local REST 문서](https://developers.kakao.com/docs/ko/local/dev-guide): 주소 검색의 `REGION`, 명칭/상위 지역/좌표와 REST 키 헤더 인증을 확인했다.
- [카카오맵 사용 안내](https://developers.kakao.com/docs/ko/kakaomap/common), [쿼터](https://developers.kakao.com/docs/ko/getting-started/quota), [운영정책](https://developers.kakao.com/terms/ko/site-policies): 앱 사용 설정과 계정별 현재 쿼터/조건을 확인해야 한다. 무료·무제한을 고정 보장하지 않는다.
- [Kakao 담당자의 MapLibre/실시간 서버 경유 사용 답변](https://devtalk.kakao.com/t/api/152137), [결과 저장 제한 답변](https://devtalk.kakao.com/t/local-api-geocoding/151848): 실시간 표시만 사용하고 결과 데이터베이스를 만들지 않는다. 서비스별 추가 계약/변경 정책은 운영자가 확인한다.
- [OpenAI Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs?api-mode=responses): 기존 strict schema 경로를 재사용하고 서버 근거/날짜 검증을 추가했다. 구조화 형식만으로 의미 정확성을 보장하지 않는다.

실제 Kakao 공식 주소 endpoint에 **인증 헤더 없이 읽기 전용 요청**을 보내 401을 확인했다. 이는 지명 검색 성공이 아니다. 실제 키가 없어 인증된 Kakao 결과·계정 권한·과금은 **미검증**이다. 조사 중 Nominatim의 연천군 공개 응답은 받았지만 이를 Kakao 결과로 사용하거나 제품의 대체 좌표로 저장하지 않았다. OpenAI 실제 유료 호출은 이번 검증에서 하지 않았다. 테스트 수/명령·종료 코드와 서비스 반영 여부는 최신 [TEST_REPORT](../TEST_REPORT.md)를 따른다.
