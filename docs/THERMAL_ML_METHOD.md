# Landsat 온도 구름 결측 ML 추정

2026-11-06 사용자 요청으로 현재 열환경 흐름에 `thermal_ml`을 추가했습니다. 기존 다른 날짜 관측 선택(`thermal_gapfill`) 및 Sentinel-2 식생 추정(`local_ridge`)과 별도입니다. RGB 사진을 생성하는 모델이나 모든 센서에 적용되는 범용 구름 제거가 아닙니다.

## 선택과 실행

Planetary Computer Landsat L2SP → 지표면 온도 분포 → **전처리 · 구름 제거 / 구름 전처리 방식 / 머신러닝으로 구름 결측 추정 · 검증 필요**를 선택합니다. 영상 1은 목표 날짜, 영상 2는 같은 위성의 참조 날짜입니다. 최대 25 km²·100,000 출력 셀·31일 검색 기간이며, 두 촬영일은 서로 달라야 합니다. 기존 2K/1km QA 기본값, canonical Item 재검증, 명시 계획 확인과 실행, 전송·시간·출력 한도를 사용합니다. 유료 OpenAI·외부 학습 API를 호출하지 않습니다.

구름 QA 표식이나 구름 최소 거리 미달 영역만 후보입니다. 불확실성 단독 탈락·일반 NoData는 추정하지 않습니다. 구름 결측이 없으면 불필요한 모델 실행을 보류합니다. 목표 영상에 맑은 공통 관측이 충분히 남고 참조 영상에는 해당 결측 위치의 유효 관측이 있어야 합니다. 두 영상 모두 완전히 흐린 경우는 해결하지 못합니다.

## 모델과 검증

NumPy로 직접 계산한 표준화 ridge 회귀(alpha=1 고정)입니다. 입력은 참조일 섭씨 온도, 정규화한 x/y 위치, 온도×x/y 상호작용 5개이며 목표일 Kelvin을 예측합니다. 사전학습 가중치나 딥러닝 모델을 다운로드하지 않습니다. 표준화 평균·분산과 계수는 학습 자료만 사용해 구합니다.

두 날짜 QA 통과 공통 관측을 120m 간격(30m 출력에서 4셀)으로 표본 추출합니다. 최소 80개 대표 표본이 필요합니다. AOI 출력 격자를 2×2 공간 구역으로 나누고 각 구역을 한 번씩 보류합니다. 해당 구역 주변 120m 완충 구간도 학습에서 제외합니다. 각 분할은 학습 40개·보류 12개 이상이어야 합니다. 공간 자기상관을 완전히 제거하거나 30m 셀을 독립적인 열관측으로 만드는 방법은 아닙니다.

전체 보류 예측 및 **각 공간 구역**에서 RMSE ≤2K, MAE ≤1.5K, 절대오차 95백분위 ≤4K를 요구합니다. 전체 RMSE가 참조일 그대로 복사보다 10% 이상, 학습 영역의 중앙값 온도 차이를 보정한 복사보다 5% 이상 좋아야 하며 동일 성능이면 통과시키지 않습니다. 기준은 구현 전 정한 앱 운영 기준이며 보편적 과학 정확도 기준이나 신뢰구간이 아닙니다. 불합격 시 ZIP·추정 지도를 만들지 않고 검증 지표를 실패 기록에 보존합니다.

통과 후 전체 대표 맑은 표본으로 재학습합니다. 참조 온도가 학습 범위 밖이거나, 가장 가까운 학습 대표점이 2km보다 멀거나, 예측 온도가 목표 학습 범위 밖이면 미해결로 남깁니다. 기존 목표일 유효 관측은 덮어쓰지 않습니다.

## 출력

`target_temperature.tif`는 목표일 유효 실측만, `estimated_only.tif`는 모델 추정만, `estimate_with_observed.tif`는 둘을 함께 보관합니다. 온도는 Kelvin/섭씨 2밴드, NoData=-9999입니다. `pixel_status.tif` 0=미해결/외부, 1=목표 관측, 2=ML 추정입니다. 지도에서도 종류별 마스크와 추정 포함 라벨을 표시합니다.

`donor_index.tif`와 `donor_date.tif`는 **추정의 참조 영상** 번호(2)와 UTC epoch 일수이며 추정값의 실제 촬영일이 아닙니다. 추정 외 위치는 각각 0/-2147483648입니다. `valid_mask.tif`의 1은 관측 또는 추정이며 실측 유효율로 해석하지 않습니다. `exclusion_mask.tif`, manifest에 모든 출처·격자·보정·QA·모델 계수·모델 해시·4구역 오차·기준선 오차·원관측/추정/미해결 면적·파일 해시를 보존합니다. 연구 기록 JSON에도 성공/보류 검증을 저장합니다.

## 실제 자료 시험

후속 실제 구름 그림자·인접 결측 데모는 [VERIFIED_ML_DEMO.md](VERIFIED_ML_DEMO.md)에 입력값과 브라우저 실검증을 기록했습니다. 183셀/0.152km² ML 추정, 맑은 공간 보류 RMSE 0.986K, QA 입력 4K/1km입니다. 다음의 인공 가림 시험과는 별도이며 실제 구름 아래 정답 검증은 여전히 아닙니다.

공개 PC Landsat 8 `LC08_L2SP_039035_20250719_02_T1` 목표, `LC08_L2SP_039035_20250703_02_T1` 참조, bbox `[-115.17,36.14,-115.13,36.18]`의 실제 온도 자료를 읽었습니다. 테스트 코드에서 중앙 폭·높이 각각 20% 구역을 **인공 구름으로 표시하고 학습에서 제외**했습니다. 생산 코드에는 인공 마스크나 fixture fallback이 없습니다.

- 맑은 영역 공간 보류 791개: ML RMSE 0.6523K / MAE 0.5189K / 95백분위 1.2573K.
- 같은 보류 위치의 참조일 복사 RMSE 8.0763K, 중앙값 차이 보정 복사 1.1530K.
- 별도 인공 가림 영역 725개 추정 픽셀의 보관한 원관측과 비교: RMSE 0.6579K / MAE 0.5655K.

이는 **한 지역·한 날짜 쌍의 맑은 픽셀 인공 가림 시험**입니다. 실제 구름 아래 온도나 다른 지역·계절의 정확도를 보증하지 않습니다. 구름이 있는 날의 지표 에너지 조건은 맑은 관측과 다를 수 있습니다. 실제 구름 아래 독립 검증·다지역 검증·현장 검증은 미완료이며, 수치를 일반적인 ‘구름 제거 정확도’로 홍보하면 안 됩니다. 근거는 `test-results/thermal-ml-20261106/public-simulated-cloud.json`과 테스트 전용 ZIP입니다.
