# AI 중심 조건 입력 — 현재 계약 (2026-11-02)

이 계약은 과거의 규칙 자동 해석·AI 버튼·지명은 지도 이동만/수동 영역 적용 계약을 대체한다. 기존 사용자 설정·센서/제품 추천 규칙·검색·미디어·A2~A4·관측 합성/ML 엔진은 유지한다. **자연어 이해와 과학적 제품 추천은 다른 책임**이다.

2026-11-03 표시 보완: 입력 근처에는 간단한 해석 상태·현재 필요한 행동·비용 고지를 표시한다. 성공은 AI 응답 성공을 뜻하며 미해결 위치/날짜/수동 충돌이 있으면 확인 필요를 우선 표시한다. 모델·설정 메시지·호출 통계·원문 근거·단계별 검증·공간 자료 출처는 접힌 `AI 해석 상세·출처·사용량`으로 옮겼고 삭제하지 않았다. 직접 입력 필드·실패 재시도·충돌 해결은 계속 제공하며 위치 재시도/직접 지명/거리 도구는 AOI 입력 옆에 있다. 검색 버튼은 같은 폼/상태를 사용하는 하나의 버튼이고, 바로가기 링크는 이동만 한다. 비어 있는 수동 폼의 HTML 필수 날짜 검증, 좌표 적용/명시 검색 시 좌표·확정 검사와 기존 AI 차단 조건은 바꾸지 않았다. `useConditionInput.ts`와 서버 해석/API는 이번 표시 변경에서 수정하지 않았다.

## 흐름과 실행 범위

문장 전체 → 기존 서버 OpenAI Responses API/strict JSON schema → 일반 코드의 구조·원문 근거·날짜/기간/상한 검사 → AI가 추출한 지명만 Kakao 주소/키워드 검색 → 실제 행정경계 또는 확인된 점+명시 거리 → 같은 폼/지도/AOI 상태 자동 반영 → 사용자 명시 검색 → 기존 장면/분석 흐름.

별도 AI 버튼은 기본 입력 단계에서 제거했다. 입력창 바로 아래에 문장이 OpenAI로 전송되고 비용/사용량이 발생할 수 있음을 표시한다. 최초 빈 화면·페이지 새로고침만으로 AI를 호출하지 않는다. 사용자 편집 후1.2초 안정화 또는 blur에서 호출한다. IME 조합 중 전송 금지, 이전 요청 취소·세대/문장 식별, 동일 입력 진행 중 억제·성공 캐시를 적용한다. 자동 영상 검색·다운로드·픽셀 분석은 없다.

기존 OPENAI_API_KEY/AI_NL_MODEL 등 설정을 그대로 사용하며 새 키·모델로 변경하지 않는다. 준비 상태는 계정의 모델 접근/실제 모델 응답 성공을 보증하지 않는다. API 문법은 [공식 Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs?api-mode=responses)를 확인했다.

2026-11-02 후속 모델 선택: 위 문장은 이 기능 최초 구현 시점의 기록이다. 사용자가 `gpt-4o`를 명시적으로 선택해 현재 서버 `.env`와 신규 설정 예시/설정 도구의 기본값을 변경했다. [GPT-4o 공식 모델 문서](https://developers.openai.com/api/docs/models/gpt-4o)는 Responses API와 Structured Outputs 지원을 표시하지만 모델을 deprecated로 표기한다. 2026-11-02 확인 단가는 입력 $2.50/백만 토큰, 출력 $10.00/백만 토큰이다. 이전 [GPT-5.6 Luna](https://developers.openai.com/api/docs/models/gpt-5.6-luna)의 $0.20/$1.20보다 높다. 상태 화면의 비용은 보고된 토큰에 비캐시 단가를 곱한 추정치이며 실제 청구액이 아니다. 서버 재시작 및 실제 계정 호출 성공은 로컬 설정 변경만으로 보증되지 않는다.

## AI 전용 추출과 실패

- `ai_conditions.py`가 목적 유형·대상·명시 검색 날짜·비교 형태/기준일/전후 기간·지명/공간 의도/거리·관측 조건·요청 해상도·대상 크기·장면 구름량 상한을 허용 스키마로 정의한다. 값에는 원문 근거와 explicit/inferred/unspecified를 보존한다. 해상도와 대상 크기는 다른 필드다.
- AI 출력에 좌표/경계/임의 작업 필드는 허용하지 않는다. 위성 사양·영상 존재·품질·다운로드 권한도 생성하지 않는다. 추천은 기존 purpose_plan/sensor_catalog로 확정 목적을 받아 결정한다.
- 일반 코드는 필드 enum/수치 범위·증거가 원문에 실제 포함됐는지·실제 달력 날짜·윤년/월말·시작/종료 순서·366일 상한을 검사한다. AI가 인용한 날짜 증거의 숫자와 값을 대조하지만 문장 전체에서 날짜/목적/지명을 찾아 조건을 제조하지 않는다. 시간대 변환 없이 UTC 달력 문자열을 사용한다.
- `2025년 8/15~8/30`의 종료 연도는 AI가 명시된 공유 연도를 추출하고 year_evidence로 근거를 제시한다. 연도 없는 월·상대 날짜는 미확정이다. 사건 기준일을 검색 월의 중간 날짜로 생성하지 않는다. 전후 두 기간은 별도 보존하며 아직 장면을 자동 선택/처리하는 기능은 아니다.
- `condition_proposals.propose_conditions/proposed_period/proposed_region/extract_places`는 기본 입력·실패 대체 경로에서 호출하지 않는다. 과거 함수/자료는 이력/독립 테스트용으로 남지만 서비스의 초기 조건 생성에 사용하지 않는다. `/request/interpret`의 resolve_conditions=true는 과거 클라이언트의 interpretation_mode=rules도 **AI 경로**로 처리한다. AI 미설정/실패면 규칙 결과를 채우지 않는다.
- `/recommend`·`/search`는 이제 확정 purpose_type을 요구한다. 자연어 purpose만으로 키워드 분류하지 않는다. 기존 선택 후 후속 작업 라우터는 확정 목적·기간·AOI를 보존하고 지원 명령만 연결한다. 그곳에서도 본문의 날짜·목적을 다시 추출하지 않는다.
- 실패/시간 초과/설정 누락/구조 오류/인증·모델 접근 거부/429/서비스 장애를 표시한다. 자동 무한 재시도는 없고 `AI 해석 재시도` 또는 `직접 입력으로 계속`을 제공한다. 후자는 사용자의 명시 선택이며 규칙 fallback이 아니다.

## 지역·실제 공간 자료

**행정경계 자동 범위는 서울특별시 전체와 제주특별자치도 전체만 지원한다.** 별칭 서울/서울시/서울특별시, 제주/제주도/제주특별자치도를 정규화한다. 제주시·제주도의 일부나 서울의 구를 전체 시도로 대체하지 않는다. 행정 단계·상위 지역·코드·중심점 포함을 대조한다. 동명/여러 후보는 이름·주소/상위 지역·행정 단계를 보여 주고 선택을 받는다. '일대' 등 공간 의도가 미지정이면 행정구역 전체 사용 여부를 다시 확인한다.

| 자료 | 기준·코드 | bbox `[서,남,동,북]` | 원본 경계 면적 |
|---|---|---|---|
| 서울특별시 | SGIS11 / 행정코드11 | `[126.76448395994285,37.42829747715147,127.18379492887969,37.70145527232949]` | 약605.3012km² |
| 제주특별자치도 | SGIS39 / 행정코드50 | `[126.14345549941781,33.112355758732,126.97265693471556,34.013233386819344]` | 약1865.0489km² |

제주 범위는 부속도서를 포함하는 **행정구역 전체**이며 제주 본섬만의 범위가 아니다. 실제 원자료의 전체 꼭짓점에서 bbox를 계산한다. 사각형에는 행정경계 밖·바다·다른 지역도 들어간다. **폴리곤 클리핑은 미지원**이며 행정경계로 잘라 분석했다고 표현하지 않는다.

- 출처: 국가데이터처 SGIS 행정구역 통계 및 경계, [공공데이터포털15129688](https://www.data.go.kr/data/15129688/fileData.do). 기준 DBF BASE_DATE=20250630, 원본 bnd_sido_00_2025_2Q. 포털의 이용허락범위 제한 없음/출처 표시 조건을 메타데이터에 기록한다. 통계서비스 경계로서 최신 법적 측량 경계를 보증하지 않는다.
- 원본 EPSG:5179 → pyproj always_xy=True → EPSG:4326 경도·위도 순서. ZIP·컴포넌트·GeoJSON SHA-256, 코드/이름/날짜·면적·geometry validity·bounds를 검증한다. 파일은 backend/app/data/boundaries/*.geojson와 *.metadata.json. 원본 제주 경계는 약10MB로 보존한다. 지도에 보내는 제주 윤곽만0.00005도 허용오차로 topology를 보존해 간소화하며 **검색 bbox는 간소화 전 원본**에서 계산한다.
- 재현: `.venv\Scripts\python.exe scripts/import-seoul-boundary.py <공식 ZIP> 39` (기존 서울 기본 인자는11). 기존 서울 파일은 다시 생성/덮어쓰지 않았다.
- Kakao는 기존 서버 REST 키/헤더만 사용한다. [공식 Local API](https://developers.kakao.com/docs/ko/local/dev-guide)의 주소 검색과 특정 장소용 키워드 검색을 분리한다. 문장 전체·OpenAI 키를 Kakao에 보내지 않는다. API는 대한민국 조회 범위와 좌표 유효성을 검사한다. 설정 준비/조회 성공/경계 확보는 별도 상태다.
- 특정 장소의 점만으로 AOI를 만들지 않는다. 명시 거리(또는 사용자가 직접 입력한 거리)가 있을 때만 WGS84 Geod 원주0.1도 표본+1m 외측 여유·외측 반올림으로 bbox를 계산한다. 허용 거리는0초과~100km, 대한민국 점 범위다. 거리 없는 장소는 주변 거리 또는 수동 AOI를 확인한다. 카카오 점을 서울시/제주도 전체 경계로 부르지 않는다.
- 다른 행정구역은 Kakao 위치/후보 조회까지 가능하지만 등록 경계가 없으면 자동 전체 범위 설정 불가다. 임의 좌표·상위 행정구역으로 바꾸지 않고 지도/좌표 직접 입력을 안내한다.

## 상태와 수정 보호

날짜·목적·분석 대상·관측 조건·해상도/크기·비교 기준일·좌표에 출처 상태를 보존한다. 확정 목적·기간·AOI와 관련 조건은 폼 상태를 단일 원천으로 사용해 검색 요청에 전달한다. 자동 결과가 명확하고 직접 수정값과 충돌하지 않으면 별도의 위치 확인/영역 적용 없이 날짜·지역·좌표·지도 bbox를 채우고 확정한다. 지도 꼭짓점 드래그·좌표 변경으로 계속 수정할 수 있다.

새 문장을 편집하면 이전 **자동** 값/자동 bbox를 비우고 이전 결과·레이어를 무효화한다. 직접 수정값은 유지하며 AI/위치 응답이 늦게 와도 덮지 않는다. 충돌 또는 새 해석/위치 확인 중에는 검색을 차단한다. `직접 수정값 유지` 또는 `문장에서 다시 적용`을 명시적으로 선택한다. AI 추론값/공간 의도 미지정도 확인 없이 확정하지 않는다. 수동으로 수정한 AOI에는 경계 참고 연결을 해제하고 다시 확정하도록 한다.

검색 bbox는 기존 가로/세로5도/기간366일 상한을 사용한다. 서울·제주 전체의 검색 범위와 기존 S2 픽셀 처리25km² 상한은 별개다. 큰 AOI를 몰래 줄이지 않는다. 열환경은 Landsat 제품 탐색이며 이번에 지표온도 계산 엔진을 추가하지 않았다. 명시된 요청 해상도·장면 구름량은 메타데이터 필터로 전달하며 미제공은 충족으로 보지 않는다. 출력 격자 메타데이터와 원관측 해상도·AOI 실제 QA를 혼동하지 않는다.

## 상한·캐시·검증의 경계

서버 AI는 입력2000자·동시1/성공128개·10분 캐시다. 환경변수로 대기시간 `AI_NL_TIMEOUT_SECONDS`(기본12, 10–90초), 출력 `AI_NL_MAX_OUTPUT_TOKENS`(기본2000, 1000–8000), 분당 `AI_NL_REQUESTS_PER_MINUTE`(기본6, 1–20회), 프로세스 `AI_NL_REQUESTS_PER_PROCESS`(기본100, 1–1000회)를 설정한다. 2026-11-05 로컬 설정·.env.example은45초/4000토큰/6회/100회다. 브라우저는 서버 설정의 분당 한도와 서버 대기+5초, 동시 문장 중복 억제·성공16개/10분 캐시를 사용한다. 수동 중단/네트워크 실패는 청구량을 모를 수 있음을 표시한다. 키 값·원문/제공처 인증 응답을 로그로 남기지 않는다. 기존 서버 가격 변수로 계산할 수 없는 비용은 미확인이다. 실제 청구는 OpenAI 계정에서 확인해야 한다. 현재 한도/집계는 프로세스 기준이며 공개 다중 서버의 과금 통제 완료가 아니다. 앱 한도 변경은 OpenAI 계정 크레딧·예산을 변경하지 않는다.

Kakao는8초/클라이언트9초·1페이지/결과 최대30개(장소 키워드15개)·분당10회/프로세스100회 상한을 유지한다. 현재 표시 중인 응답만60초 재사용하고 서버 DB·영속 캐시·localStorage·manifest로 축적하지 않는다. 공식 로컬 경계 파일은 별도로 캐시한다.

기본 검증의 OpenAI/Kakao는 **mock**이다. 테스트 transport는 실제 유료 OpenAI 호출과 Kakao 쿼터 사용을 차단한다. 공식 SGIS 실제 다운로드/좌표 검증은 별도 근거이며 실제 Kakao 성공으로 간주하지 않는다. 실제 유료 AI 검증은 대상 모델·예상 호출 수/비용 범위를 알리고 승인받은 후에만 실행한다. 이번 작업은 그 호출을 하지 않았다. 실행 명령·종료 코드·브라우저/실연결 구분은 최신 TEST_REPORT를 따른다.

확인 예: `2025년 8/15~8/30까지 제주도의 지표면 온도를 알고 싶어`, `2025년 8월 서울시 지표면 온도`, `2025년 8월 제주공항 주변 1km의 지표면 온도`. 실제 모델의 이해 정확도와 실제 Kakao 결과는 승인된 실연결 검증 전까지 미검증이다.
